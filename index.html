Code forensics / Digital detective

Small clues.
Short stories. Clear code.

Dijital Dedektif Studio turns code-forensics ideas into short educational videos for the creator’s own TikTok account.

A single-creator production tool, not an account-management service or a tool for posting to other people’s accounts. TikTok authorization uses Login Kit; publishing uses the official Content Posting API’s Direct Post flow, never browser upload automation.

From evidence to episode

  1. 01 / SCRIPT

    Find the story

    Gemini generates a structured educational script, using previous titles to avoid repeating topics.

  2. 02 / VOICE

    Give it a voice

    Edge-TTS produces narration and word-timed captions from the script.

  3. 03 / RENDER

    Build the short

    Generated images, stock photos, or local cards become a vertical video with narration and captions, rendered with FFmpeg.

  4. 04 / PUBLISH

    Post to the creator’s account

    After account authorization and required platform approvals, the configured pipeline uploads through TikTok’s official API and checks processing status.

Creator-controlled, platform-dependent. The creator is responsible for reviewing content and meeting TikTok’s consent and sharing requirements before enabling live posts. API access, audit approval, and public visibility are not guaranteed. Dry runs do not upload.
